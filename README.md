# PolyWorld! Client Source
PolyWorld! is a UGC Sandbox platform created and developed by Crzy mainly in the C programming language, the platform launched on the 30th of May with the release of the browser client following around a week after.

PolyWorld! aims to recreate the core experience of classic Roblox, with features such as a studio with lua support, extensive avatar customization and a full client.
